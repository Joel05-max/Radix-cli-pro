# Radix CLI

Predictive Infrastructure Engine & AI-Powered Auto-Remediation CLI.

## Quick Commands

- `radix ask` - Conversational AI diagnosis
- `radix monitor` - Live server telemetry stream
- `radix fix` - Auto-patching engine
- `radix fix --dry-run` - Preview patch diff
- `radix report` - Generate executive HTML audit
- `radix init` - Local project configuration
